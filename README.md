# Enseigner avec Coolselector®2 — ressources pédagogiques

Tutoriel, TP et grilles d'évaluation pour former au **dimensionnement frigorifique** avec
Coolselector®2, le logiciel de sélection gratuit de Danfoss.

**→ [Accéder aux documents](https://frigorx.github.io/coolselector-formation/)**

---

## Ce que contient ce dépôt

| Document | Public | Format |
|---|---|---|
| **Tutoriel complet** — prise en main guidée, 2 parcours, 8 exercices corrigés | Tous niveaux | PDF · 11 Mo |
| **TP élève — chambre froide** — 2 h, à photocopier tel quel | Bac Pro MFER · CAP | PDF · 2,9 Mo |
| **Étude de cas — climatisation** — 4 h, dossier à rendre | TP TECVC · BTS | PDF · 2,8 Mo |
| **Grilles d'évaluation par compétences** — échelle 0-4, conversion en note | Enseignants | PDF + outil en ligne |
| **Fiche d'installation** — où trouver le logiciel, quoi vérifier avant la séance | Enseignants | PDF · 0,2 Mo |

Un **calculateur de notes** est également utilisable directement dans le navigateur :
vous cochez les niveaux, il calcule la note sur 20. Rien n'est envoyé ni enregistré.

## Adossement aux référentiels

Les activités renvoient aux codes officiels :

- **Bac Pro MFER** — unité U2, épreuve E2 : `C1`, `C2`, `C3` · tâches `A1T1`, `A1T2`, `A1T4`
- **TP TECVC** — bloc CCP3 (AT3) : `CP8` *Réaliser les calculs d'apports thermiques*,
  `CP9` *Réaliser l'étude d'une installation de climatisation*

Les grilles indiquent aussi ce qu'on **ne peut pas** évaluer avec ces TP : devant un écran, il n'y a
ni geste, ni fluide, ni client, donc pas de quoi juger la réalisation ni la maintenance.
